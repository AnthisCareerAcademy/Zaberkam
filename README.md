## Zaberkam
Welcome to Zaberkam, a multiplayer dungeon-crawling game! This was the PM Software Development Capstone project.

## To Build
Clone the repository and add it as a Unity project to modify the project. Alternatively, we have a "release" that can be downloaded, which includes a playable .EXE file.

(The game is not complete--there are still several kinks that would need to be worked out in a final release. Also, it doesn't have sound.)
